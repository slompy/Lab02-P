1. Decimal хранит числа в десятичной форме, и идеален для денег, так как выполняет расчеты без округлений, с абсолютной точностью. А Double хранит числа в двоичной системе, что не всем вычислениям подойдет. Double вычислит лишние или потерянные числа, которые приведут так или иначе к ошибкам.
2. Он сбросится до нуля, то есть если 255 прибавить 1, то байт станет 0.
3. Var в C# моментально определяет тип переменной, прямо во время написания кода. Когда как в Python он определяется во время выполнения программы. 
4. Он всегда возвращает строку, независимо от написанного.
5. Int.Parse при ошибке вызовет ошибку, и она закроется. А ошибка в Int.TryParse не будет ронять программу, он ведь просто мягко говорит, получилось ли конвертация или нет.
6. При ошибке вернёт False, конвертация провалилась. После слова Out запишется значение по умолчанию типа int - 0.
7. Его стоить использовать, когда пользователь может очевидно ошибиться в написании нужных данных для выполнения кода.
